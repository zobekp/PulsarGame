# DPI Lab

Aimlabs-style trainer that finds the mouse DPI you aim best at. Single file, no build step.

**Use it:** download `index.html` and open it in Chrome/Edge (pointer lock + raw input work from a local file),
or serve the folder with any static server.

1. Enter your current DPI, game and in-game sensitivity.
2. Pick a drill (Flick is the most DPI-sensitive), set the DPI ladder, hit **Start**.
3. Play each blind, shuffled segment. Results give a recommended DPI plus eDPI / cm-per-360.

All tunables are in the `CONFIG` block at the top of the script.
